# xhs-storyboard 是什么

xhs-storyboard 是一个给 Claude Code 和 Codex 用的 Skill。它把一篇文章或一份笔记做成一组小红书图文：3:4 竖图，每张 1080×1440。

## 先出分镜，再出图

它不直接出图。第一步是读材料，定下这组图想让读者带走的一句话。第二步是出分镜表：每一页用什么版式、写什么字、要不要配图。配图来源分三种：none 是不配图，ready 是用现成的图，yours 是只有作者本人能给的真实截图。

作者确认分镜表以后，它才写 cards.json，运行渲染脚本出图。脚本报了错，就按提示改，再跑一遍，直到全部通过。

## 一页只讲一件事

一组图一般 5 到 9 页，每页只讲一件事，每页都为那句带走点服务。

## 版式和外观

一共 15 种版式：封面、一句话、要点、步骤、对比表、窗口截图、手机截图、代码、提示词、对话、数据、对错、时间线、清单、结尾。外观有 2 套：浅色的「简约」和深色的「极客」。

只要给一个主色，脚本就推出整套配色：底色、正文、辅助文字、分隔线都取主色的色相。它会检查文字和底色的对比度，低于 4.5:1 就自动调深或调浅，并说明改了什么。

## 互动动机

分镜时先选 1 到 2 个读者参与的动机，比如「想看结果」「想带入自己」，封面和最后一页围绕它写，最后一页用一个问题收尾。封面可以写 2 到 3 个版本，脚本分别出图，挑一张用。

## 出图前检查

渲染脚本调用本机的 Chrome 无头模式，npm 依赖是 0 个。出图前会检查：

- 文字有没有超出卡片；
- 有没有留下占位文字；
- 标成 yours 的图有没有给；
- 提供了原文时，卡片上的每个数字都要能在原文里找到。

任何一项没通过，脚本就报错，不出图。标成 yours 却没给图时，它不会画一张假截图来凑数。
